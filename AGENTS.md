# Project layout

Keep `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` at the repository root. GitHub Pages needs `index.html` there.

Put all other new files in the numbered folder that matches their purpose:

- `00_planning/` — notes and sketches.
- `01_data/` — data files.
- `02_validation/` — hand calculations and test cases.
- `03_output/` — screenshots and exported results.

Save every new file in the appropriate folder; do not add project files at the root beyond the four listed above.
